# Segurança

Este repositório distribui skills (arquivos de texto/instrução) para agentes de IA. Antes de instalar
qualquer skill, leia a licença, o `SKILL.md` e qualquer arquivo de apoio (`references/`, `templates/`,
`scripts/`). Não execute scripts nem forneça credenciais sem entender o que vão fazer.

## Reportar um problema

Abra uma issue neste repositório ou escreva para o contato da Claricia. Resposta em até 72h.

## O que NÃO fazer

Não ensine ou peça para ignorar um bloqueio de segurança (`--force`) em qualquer ferramenta de instalação.
Se uma skill foi bloqueada por um scanner, o problema é da skill — corrija a skill, não contorne o scanner.
