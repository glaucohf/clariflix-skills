# Definindo tolerância aceitável

Pergunte antes de aplicar qualquer tolerância: "qual diferença é aceitável sem investigar — em valor absoluto ou percentual?"

Exemplos comuns:
- Arredondamento de centavos: tolerância de R$0,05 por linha é comum e raramente esconde erro real.
- Percentual sobre valores grandes: 0,5% pode ser aceitável para lotes, mas nunca para linha única de alto valor.

Nunca defina a tolerância sozinho sem confirmar com quem pediu a conferência — é uma decisão de negócio, não técnica.
