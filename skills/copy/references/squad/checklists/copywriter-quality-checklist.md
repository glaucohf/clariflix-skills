# Copywriter Quality Checklist

## Purpose

Validar se o output de um copywriter específico está fiel ao seu estilo original. Use este checklist **após gerar copy** para garantir distintividade e autenticidade.

> **Integração:** Este checklist complementa as métricas em `docs/distinctiveness-metrics.md`

---

## Como Usar

1. Gere copy com um copywriter específico
2. Abra a seção do copywriter usado
3. Marque os checkpoints presentes
4. Calcule o score
5. Se <70%, ajuste o output ou regenere

---

## Scoring System

| Score | Status | Ação |
|-------|--------|------|
| 90-100% | ✅ Excelente | Publicar - altamente distintivo |
| 70-89% | 🟡 Bom | Pequenos ajustes - estilo presente |
| 50-69% | ⚠️ Regular | Revisão necessária - estilo fraco |
| <50% | ❌ Falhou | Regenerar - não parece o copywriter |

---

## SEÇÃO GENÉRICA (Todos Copywriters)

### Fundamentos (5 pontos)
- [ ] Copy tem estrutura clara (headline, body, CTA)?
- [ ] Benefícios estão presentes (não só features)?
- [ ] Tom é consistente do início ao fim?
- [ ] Linguagem é apropriada para o avatar?
- [ ] Copy flui naturalmente quando lido em voz alta?

## COPYWRITERS ESPECÍFICOS

---

### 1. Gary Halbert (🎯 O Príncipe do Print)

**Signature Elements (8 checkpoints):**

- [ ] **Abertura pessoal:** Começa com "Caro amigo" ou variação pessoal?
- [ ] **História pessoal:** Tem storytelling em primeira pessoa no lead?
- [ ] **Tom direto:** Linguagem é direta, sem rodeios corporativos?
- [ ] **Urgência natural:** Urgência parece orgânica (não forçada)?
- [ ] **Garantia ousada:** Garantia é bold e confiante?
- [ ] **PS poderoso:** Tem PS com hook ou reforço?
- [ ] **Emotional appeal:** Apela para emoções viscerais?
- [ ] **Sentenças curtas:** Maioria das sentenças <20 palavras?

**Score Halbert:** ___/8 = ___%

**Red Flags (NÃO deve ter):**
- ❌ Tom corporativo ou formal
- ❌ Linguagem passiva
- ❌ Falta de história pessoal
- ❌ Urgência artificial óbvia

---

### 2. David Ogilvy (🎩 O Pai da Publicidade)

**Signature Elements (8 checkpoints):**

- [ ] **Headline com benefício + número:** Ex: "Como X pessoas conseguiram Y"?
- [ ] **Provas factuais:** Tem dados, estatísticas, pesquisa?
- [ ] **Tom sofisticado:** Linguagem é elegante mas acessível?
- [ ] **Credibilidade institucional:** Menciona fontes, autoridades?
- [ ] **Long-form informativo:** Copy é educativo, não só vendedor?
- [ ] **Sem superlativos vazios:** Evita "o melhor", "incrível" sem prova?
- [ ] **Respeito ao leitor:** Trata leitor como inteligente?
- [ ] **Foco na marca:** Contribui para imagem de marca?

**Score Ogilvy:** ___/8 = ___%

**Red Flags (NÃO deve ter):**
- ❌ Hipérboles sem fundamento
- ❌ Tom agressivo ou urgente demais
- ❌ Linguagem informal/casual excessiva
- ❌ Falta de dados/fatos específicos

---

### 3. Eugene Schwartz (🧠 O Mestre do Desejo)

**Signature Elements (8 checkpoints):**

- [ ] **Big idea central:** Uma ideia grande e transformadora é identificável?
- [ ] **Adequação de consciência:** Copy se adequa ao nível de awareness?
- [ ] **Canaliza desejo existente:** Não cria desejo, direciona o que existe?
- [ ] **Intensificação gradual:** Emoção cresce ao longo do copy?
- [ ] **Conceito único:** Apresenta conceito/mecanismo diferenciado?
- [ ] **Headline de nível certo:** Headline match com awareness level?
- [ ] **Transformação prometida:** Foca em transformação, não features?
- [ ] **Fascinations presentes:** Tem bullets que criam curiosidade?

**Score Schwartz:** ___/8 = ___%

**Red Flags (NÃO deve ter):**
- ❌ Copy genérico sem big idea
- ❌ Headline muito direta para público frio
- ❌ Falta de progressão emocional
- ❌ Mecanismo não explicado

---

### 4. Claude Hopkins (🔬 O Cientista)

**Signature Elements (8 checkpoints):**

- [ ] **Claim específico:** Promessas são específicas e mensuráveis?
- [ ] **Oferta clara:** Oferta está cristalina e testável?
- [ ] **Elementos testáveis:** Headlines/CTAs podem ser A/B testados?
- [ ] **Linguagem científica acessível:** Usa dados sem ser chato?
- [ ] **Prova de teste:** Menciona testes, resultados, experimentos?
- [ ] **Números específicos:** Ex: "7 dias" não "alguns dias"?
- [ ] **Cupom/Rastreamento implícito:** Ação é rastreável?
- [ ] **Sem exageros:** Claims são defensáveis?

**Score Hopkins:** ___/8 = ___%

**Red Flags (NÃO deve ter):**
- ❌ Promessas vagas ("melhores resultados")
- ❌ Falta de especificidade
- ❌ Copy impossível de testar
- ❌ Linguagem emocional sem dados

### 5. Dan Kennedy (💰 O Millionaire Maker)

**Signature Elements (8 checkpoints):**

- [ ] **Urgência desde o início:** Urgência aparece cedo no copy?
- [ ] **Deadline inviolável:** Tem data/hora específica?
- [ ] **Escassez real:** Limitação é genuína e clara?
- [ ] **Stack de valor explícito:** Valor de cada item está visível?
- [ ] **CTA agressivo:** Call-to-action é direto e imperativo?
- [ ] **NO B.S. attitude:** Sem rodeios, direto ao ponto?
- [ ] **Foco em conversão:** Todo elemento serve para converter?
- [ ] **Consequência clara:** O que acontece se não agir está claro?

**Score Kennedy:** ___/8 = ___%

**Red Flags (NÃO deve ter):**
- ❌ Urgência vaga ou contínua
- ❌ Tom relaxado ou casual
- ❌ Falta de deadline específico
- ❌ CTA fraco ou múltiplas opções

- [ ] **Tom conversacional:** Parece diálogo, não monólogo?
- [ ] **Questions retóricas:** Usa perguntas para engajar?
- [ ] **PS com curiosidade extra:** PS tem hook adicional?

**Score Benson:** ___/8 = ___%

**Red Flags (NÃO deve ter):**
- ❌ Copy que não soa bem lido em voz alta
- ❌ Falta de emoção/conexão

## Integração com Métricas de Distintividade

Após validar com este checklist, verifique também:

1. **Métricas Quantitativas** (de `distinctiveness-metrics.md`):
   - SLA (Sentence Length Average) está no range?
   - VR (Vocabulary Richness) está no range?
   - PWR (Power Words Ratio) está no range?

2. **Comparação com Outros Copywriters**:
   - Output é >50% distinto de outros copywriters?
   - Não há "contaminação" de estilos não intencionais?

3. **Red Flags Cross-Check**:
   - Nenhum red flag de OUTRO copywriter está presente?

## Quick Reference por Uso

### Para Validação Rápida
Use apenas a seção do copywriter específico (8 checkpoints).
Target: >6/8 (75%)

### Para Validação Completa
Use Fundamentos (5) + Copywriter Específico (8) + Métricas Quantitativas.
Target: >85% combinado

### Para Novos Copywriters
Use como template para criar seção de checkpoints.
Requirement: 8 checkpoints baseados em Signature Elements.
