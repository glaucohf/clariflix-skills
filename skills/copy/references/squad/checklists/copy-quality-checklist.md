# Copy Quality Checklist

## Visão Geral

Use este checklist para validar qualquer peça de copy antes de publicar. Baseado nos princípios dos 8 copywriters lendários do CopywriterOS.

---

## 1. HEADLINE CHECK ✍️

### Clareza
- [ ] Benefício principal está claro em < 3 segundos?
- [ ] Avatar sabe que é para ele?
- [ ] Promessa é específica (não genérica)?

### Impacto
- [ ] Cria curiosidade ou desejo?
- [ ] Diferencia de concorrentes?
- [ ] Funciona isoladamente (sem contexto)?

### Técnica
- [ ] < 15 palavras (idealmente)?
- [ ] Sem jargão ou termos confusos?
- [ ] Testável (pode fazer A/B)?

**Teste Halbert:** Se eu recebesse isso no correio, abriria?

---

## 2. LEAD CHECK 📖

### Engajamento
- [ ] Prende atenção nos primeiros 5 segundos?
- [ ] Leitor quer continuar lendo?
- [ ] Conecta emocionalmente?

### Relevância
- [ ] Fala diretamente com a dor/desejo do avatar?
- [ ] Qualifica o leitor correto?
- [ ] Estabelece contexto necessário?

### Flow
- [ ] Transição suave para o body?
- [ ] Cada frase "compra" a próxima?

**Teste Sugarman:** É um "slippery slide" - impossível parar?

---

## 3. BODY COPY CHECK 📝

### Estrutura
- [ ] Problema claramente articulado?
- [ ] Solução apresentada como herói?
- [ ] Mecanismo explicado (como funciona)?
- [ ] Benefícios > Features?

### Persuasão
- [ ] Prova social presente (testemunhos, números)?
- [ ] Credibilidade estabelecida?
- [ ] Objeções endereçadas?
- [ ] Gatilhos mentais aplicados eticamente?

### Legibilidade
- [ ] Parágrafos curtos (1-4 linhas)?
- [ ] Subheadings guiam a leitura?
- [ ] Bullets destacam pontos-chave?
- [ ] Linguagem conversacional?

**Teste Ogilvy:** Tem fatos específicos, não só adjetivos?

---

## 4. OFERTA CHECK 💰

### Clareza
- [ ] O que está incluído é 100% claro?
- [ ] Preço é justificado pelo valor?
- [ ] Stack de valor é visual e fácil de entender?

### Valor
- [ ] Valor percebido > preço (idealmente 10x)?
- [ ] Bônus são relevantes (não enchimento)?
- [ ] Diferencial vs alternativas é claro?

### Risco
- [ ] Garantia presente e clara?
- [ ] Garantia remove objeções de risco?
- [ ] Termos são específicos?

**Teste Kennedy:** A oferta é irrecusável?

---

## 5. URGÊNCIA CHECK ⏰

### Autenticidade
- [ ] Urgência é GENUÍNA (não fabricada)?
- [ ] Razão para urgência faz sentido?
- [ ] Deadline será cumprido?

### Tipos de Urgência
- [ ] Tempo (data específica)?
- [ ] Quantidade (vagas/unidades)?
- [ ] Bônus (expira)?
- [ ] Preço (sobe)?

### Comunicação
- [ ] Urgência está visível e clara?
- [ ] Consequência de não agir está clara?

**Teste Ético:** Eu me sentiria bem se um amigo comprasse por causa dessa urgência?

---

## 6. CTA CHECK 🎯

### Clareza
- [ ] Ação específica está clara?
- [ ] Próximo passo é óbvio?
- [ ] Não há confusão sobre o que fazer?

### Visibilidade
- [ ] CTA é impossível de perder?
- [ ] Repetido em pontos estratégicos?
- [ ] Destaca visualmente?

### Linguagem
- [ ] Verbo de ação presente?
- [ ] Benefício incluído no CTA?
- [ ] Tom alinhado com copy?

**Bons CTAs:**
- ✅ "Quero meus resultados agora"
- ✅ "Começar minha transformação"
- ✅ "Garantir minha vaga"

**CTAs fracos:**
- ❌ "Clique aqui"
- ❌ "Enviar"
- ❌ "Comprar"

---

## 7. PROVA SOCIAL CHECK 👥

### Autenticidade
- [ ] Testemunhos são reais?
- [ ] Resultados são verificáveis?
- [ ] Fotos/nomes são genuínos?

### Relevância
- [ ] Testemunhos são de avatares similares?
- [ ] Resultados são representativos?
- [ ] Objeções comuns são endereçadas?

### Quantidade
- [ ] Números impressionam? (clientes, resultados, etc.)
- [ ] Logos de credibilidade presentes?
- [ ] Press/mídia se aplicável?

---

## 8. COPY TÉCNICO CHECK 🔧

### SEO (se aplicável)
- [ ] Keyword principal presente?
- [ ] Meta description otimizada?
- [ ] Headers estruturados (H1, H2, etc.)?

### Mobile
- [ ] Legível em tela pequena?
- [ ] Parágrafos não muito longos?
- [ ] CTAs fáceis de tocar?

### Legal
- [ ] Disclaimers necessários presentes?
- [ ] Claims são defensáveis?
- [ ] Termos de uso/privacidade linkados?

---

## 9. CHECKLIST POR TIPO DE COPY

### Sales Page
- [ ] Headline com benefício
- [ ] Problema articulado
- [ ] Solução apresentada
- [ ] Prova social
- [ ] Oferta clara
- [ ] Garantia
- [ ] Urgência (se aplicável)
- [ ] CTA múltiplas vezes
- [ ] FAQ

### Email
- [ ] Subject < 60 chars
- [ ] Preview text otimizado
- [ ] Opening hook forte
- [ ] Um objetivo por email
- [ ] CTA claro
- [ ] PS com valor

### Anúncio
- [ ] Hook em < 3 segundos
- [ ] Benefício específico
- [ ] Dentro dos limites de caracteres
- [ ] CTA impossível de ignorar
- [ ] Imagem e copy alinhados

### Landing Page
- [ ] Uma ação apenas
- [ ] Benefício claro above the fold
- [ ] Form com mínimo de campos
- [ ] Zero distrações
- [ ] Mobile-first

---

## 10. REVISÃO FINAL ✅

### Leitura em Voz Alta
- [ ] Soa natural quando lido?
- [ ] Ritmo está bom?
- [ ] Alguma frase trava?

### Perspectiva do Avatar
- [ ] Eu compraria se fosse o avatar?
- [ ] Minhas objeções foram respondidas?
- [ ] O valor está claro?

### Teste de 24 Horas
- [ ] Releu no dia seguinte?
- [ ] Ainda funciona com "olhos frescos"?
- [ ] Cortou tudo que não é essencial?

---

## SCORE CARD

Conte os ✅ e calcule:

| Score | Classificação | Ação |
|-------|---------------|------|
| 90-100% | Excelente | Publicar |
| 75-89% | Bom | Pequenos ajustes |
| 60-74% | Regular | Revisão necessária |
| < 60% | Precisa trabalho | Reescrever seções |

---

## PRINCÍPIO FINAL

> "Se você não consegue explicar em uma frase por que alguém deveria comprar, seu copy não está pronto."
> — Adaptado de todos os 8 mestres
