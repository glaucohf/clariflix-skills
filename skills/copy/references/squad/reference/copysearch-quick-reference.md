## CARD 1: EVIDENCE HIERARCHY

```
┌─────────────────────────────────────────────────────────────────┐
│                     EVIDENCE HIERARCHY                          │
│                  "Trust behavioral data over stated intentions" │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  🥇 GOLD    │ Direct response results, sales data, verified   │
│             │ technical documentation, test market results     │
│             │ → USE IN: Headlines, primary claims              │
│             │                                                   │
│  🥈 SILVER  │ Expert interviews, systematic competitive        │
│             │ analysis, diagnostic metrics (readership, CTR)   │
│             │ → USE IN: Supporting claims                      │
│             │                                                   │
│  🥉 BRONZE  │ Consumer stated preferences, focus groups,       │
│             │ recall testing, surveys                          │
│             │ → USE IN: Hypothesis only, with qualifiers       │
│             │                                                   │
│  ❌ REJECT  │ Creative awards, unverified claims, intuition,   │
│             │ "everyone knows" statements                      │
│             │ → USE IN: NEVER                                  │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## CARD 2: ANCHOR FACT CRITERIA

```
┌─────────────────────────────────────────────────────────────────┐
│                    ANCHOR FACT TEST                             │
│            "At 60 miles an hour the loudest noise..."           │

│                                                                 │

│      ❌ "Customers love us"                                     │
│      ✅ "4.9 stars from 12,847 verified reviews"                │
│                                                                 │
│  [ ] RELEVANT                                                   │
│      Connects to consumer benefit                               │
│      ❌ "Made with aerospace-grade aluminum"                    │

```

## CARD 5: SKIN IN THE GAME GATES

```
┌─────────────────────────────────────────────────────────────────┐
│                VALIDATION GATES                                 │
│           (All 4 gates must pass for critical claims)           │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  GATE 1: SOURCE                                                 │
│  "Where does this information come from?"                       │
│  [ ] Has traceable source (URL, document, quote)                │
│  [ ] Insights without source DISCARDED                          │
│                                                                 │
│  GATE 2: VERIFICATION                                           │
│  "Can I verify this independently?"                             │
│  [ ] Cross-checked with 2+ sources                              │
│  [ ] Unverified insights MARKED as such                         │
│                                                                 │
│  GATE 3: REPRESENTATIVENESS                                     │
│  "Does this represent the whole?"                               │
│  [ ] Quantitative analysis exists                               │
│  [ ] Not cherry-picking isolated examples                       │
│                                                                 │
│  GATE 4: HUMAN                                                  │
│  "Has an expert validated this?"                                │
│  [ ] Critical claims reviewed by human specialist               │
│                                                                 │
│  ─────────────────────────────────────────────────────────────  │
│  PASS ALL 4 = Ready to use in copy                              │
│  FAIL ANY 1 = Review and resolve before using                   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## CARD 9: RED FLAGS

```
┌─────────────────────────────────────────────────────────────────┐
│                    RED FLAGS                                    │
│              (STOP if any of these are true)                    │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ❌ Insight seems TOO GOOD to be true                           │
│     → Probably is. Verify or discard.                           │

│     → AI frequently fabricates statistics                       │
│                                                                 │

│     → "Consumers prefer..." needs numbers                       │
│                                                                 │

│     → Client knows their business                               │
│                                                                 │
│  ❌ Cannot be VERIFIED independently                            │
│     → If you can't verify, don't use                            │
│                                                                 │
│  ─────────────────────────────────────────────────────────────  │
│  ACTION: If ANY red flag → STOP and investigate                 │
```

## CARD 10: CONFIDENCE SCORING

```
┌─────────────────────────────────────────────────────────────────┐
│                 CONFIDENCE SCORING                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  HIGH (90%+)                                                    │
│  ──────────────────────────────────────────────                 │
│  • Multiple independent sources                                 │
│  • Direct verification possible                                 │
│  • Primary source accessible                                    │
│  → ACTION: Use in headlines and primary claims                  │
│                                                                 │
│  MEDIUM (70-89%)                                                │
│  ──────────────────────────────────────────────                 │
│  • Single credible source                                       │
│  • Consistent with other evidence                               │
│  • Source is authoritative                                      │
│  → ACTION: Use in supporting claims, note source                │
│                                                                 │
│  LOW (50-69%)                                                   │
│  ──────────────────────────────────────────────                 │
│  • Single source, cannot verify                                 │
│  • Source credibility uncertain                                 │
│  → ACTION: Human review required, use qualifiers                │
│                                                                 │
│  UNACCEPTABLE (<50%)                                            │
│  ──────────────────────────────────────────────                 │
│  • Speculation or inference                                     │
│  • No source or conflicting info                                │
│  → ACTION: DISCARD — do not use                                 │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```
