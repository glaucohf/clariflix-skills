# Agrupar por intenção, não por palavra

Perguntas que parecem diferentes mas têm a mesma intenção:
- "Vocês abrem aos sábados?" / "Funciona no fim de semana?" / "Tem atendimento sábado?" → 1 grupo: horário de sábado.
- "Quanto custa?" / "Qual o valor?" / "Tem desconto?" → separe em 2 grupos: preço-base (1 resposta) e desconto (outra resposta, mais cuidadosa).

Regra prática: se a mesma resposta serve para as duas perguntas sem editar nada, é o mesmo grupo. Se precisar mudar uma palavra que muda o sentido (ex.: desconto muda a resposta), são grupos diferentes.
